# Nafas 3D-style asset catalog

Transparent individual SVG assets:
- microphone-open.svg — speaking/open microphone state
- microphone-muted.svg — muted microphone state
- speaker-seat.svg — circular speaker seat
- vip-badge.svg — VIP badge
- gift-rose.svg, gift-crown.svg, gift-diamond.svg, gift-heart.svg — separate gift assets
- avatar-frame-gold.svg — transparent avatar frame overlay
- room-owner-crown.svg — room owner marker
- room-background.svg — scalable 1080x1920 room background

SVGs are editable vector source assets. The visual depth is illustrated with gradients and highlights; these are 3D-style vector graphics, not rendered 3D model files. Further assets and app integration/testing are still required before claiming production readiness.
