# Nafas asset library

Original editable vector source assets live here. SVG is the master format for scalable brand and UI artwork; export production variants to PNG/WebP and animation formats only where needed.

## Included
- `brand/nafas-mark.svg`: initial app mark.
- `icons/*.svg`: microphone, room seat, gift, VIP and frame icon sources.

These are initial original source assets, not a complete production asset pack yet. Before release, validate visual consistency, accessibility, rendering, animation performance and licensing for every third-party asset.
